# q.bit — блочное программирование и симулятор платы

Редактор блоков (как Scratch) для платы q.bit и её цифровой двойник в браузере: 8 магнитных портов, 33 модуля, программа из блоков запускается либо на виртуальной плате, либо на настоящей. Всё работает без интернета и без установки.

**Как это устроено и почему так: [docs/IDE.md](docs/IDE.md).** Протокол с платой: [docs/PROTOCOL.md](docs/PROTOCOL.md). Python-справочник модуля `qbit`: [docs/QBIT-API.md](docs/QBIT-API.md). Модуль для прошивки: [mpy/README.md](mpy/README.md).

## Как запустить

| Способ | Как |
|---|---|
| Просто открыть | двойной щелчок по `ide/index.html` (редактор блоков + плата), `ide/simulator.html` — только плата |
| С телефона / планшета в той же Wi-Fi | `node ide/tools/serve.js` → `http://<IP-компьютера>:8766/` |
| Без железа попробовать «настоящую» плату | `node ide/tools/fake-board.js` → `http://localhost:8780/` (IDE подключится сама) |
| Один файл (его раздаёт плата) | `python -X utf8 ide/tools/build.py` → `ide/dist/qbit-ide.html` (1,4 МБ, 380 КБ в gzip) и `qbit-sim.html` |

Проверки: `node ide/tests/run-all.js` (все слои, ~1,5 минуты; `--quick` — без браузера).

Если поменялся каталог модулей / паспорта / панели: `python -X utf8 ide/tools/gen_hw_data.py` — пересоздаёт `js/data/hw-data.js` из `catalog.py`, `passport.py`, `kit_panel.py`.

Звуки блоков (щелчок, стыковка, удаление) — родные звуки Blockly, встроены в `js/ide/sounds.js` (иначе при открытии файла двойным щелчком браузер не даёт их загрузить); после обновления Blockly: `python -X utf8 ide/tools/gen_sounds.py`. Кнопка «Звук» в шапке выключает и их.

## Дизайн

Внешний вид IDE сделан по макету Figma «qcode» (кадр Desktop 1920×1080): яркая голубая шапка с логотипом «qblock», светло-голубая страница, белые скруглённые карточки, категории блоков Scratch-цветов с подписями под кружками, шрифт Montserrat (`vendor/fonts`, лицензия OFL). Слева карточка платы с кнопками подключения / пауза / стоп / запуск, справа колонка категорий, блоки и рабочее поле. Всё, чего нет в макете (консоль, модули, данные, поиск, Python), добавлено в том же стиле: вкладки под картинкой платы, поиск и переключатель «Блоки / Python» в шапке. Название «qblock» меняется в `index.html`.

Правила вида: плоско (никаких теней: ни у карточек и кнопок, ни у Blockly, ни у модулей на картинке платы), без эмодзи и значков-символов — все иконки линейные SVG из одного набора `js/ui/icons.js` (в HTML: `<svg class="ic"><use href="#i-play"/></svg>`, из кода: `Q.icon('play')`; цвет берут у текста). Колонка категорий не прокручивается ни в какую сторону: строки делят её высоту поровну, кружки и подписи подстраиваются под высоту окна (подписи пропадают, когда места мало), добавленная поиском строка тоже влезает. Лишнего текста нет: подсказки «как пользоваться», счётчики, теги у карточек и метки времени в консоли показывает только отдельная страница `simulator.html`.

## Языки: русский, узбекский, английский

Кнопка с глобусом справа в шапке («RU», «UZ», «EN») меняет язык всего интерфейса: шапки и меню, блоки (их текст, подсказки, выпадающие списки), модули и их панели, примеры, сообщения об ошибках, а также меню и окна самого Blockly. Выбор запоминается; страница перезагружается, проект при этом сохраняется. Адрес `index.html?lang=uz` открывает страницу на нужном языке сразу. Узбекский — латиницей (`oʻ`, `gʻ`, `maʼlumot`). Тексты на плате (сообщения прошивки и модуля `qbit` для MicroPython) пока русские.

Устройство: исходный язык программы — русский, и русская фраза служит ключом: `T('Запустить')`, с подстановкой `T('порт %1', n)`. Словари — `js/i18n/en.js` и `uz.js` (ядро — `js/core/i18n.js`). Новый текст: написать его по-русски в `T('…')`, затем `node ide/tools/i18n_keys.js --missing` покажет, чего не хватает в словарях; `tests/i18n.test.js` не даст забыть (проверяет полноту, одинаковые `%1 %2`, отсутствие русских букв в переводе и неиспользуемые строки), а `tests/ui.test.js` обходит весь интерфейс на английском и узбекском и ищет оставшийся русский текст.

## Блочная IDE: что умеет

* Блоки: события (в том числе «когда кнопка нажата», «когда PAIR», сообщения между скриптами), управление, действия и датчики **по каждому из 33 модулей**, операторы, переменные, свои блоки-функции. Порт выбирается в самом блоке, список портов подписан тем, что на них стоит.
* Запуск, пауза, стоп; выполняемый блок светится; ошибка на понятном языке (русском, узбекском или английском) и блок с ней краснеет; блоки не под «когда …» помечены предупреждением.
* Вкладка «Python» показывает настоящий код, который собрался из блоков.
* Внизу: «Консоль» (вывод программы), «Устройства» (симулятор или настоящая плата по Wi-Fi / USB) и «Данные» (значения всех модулей в реальном времени).
* 9 готовых примеров («Мигаем светодиодом», «Ручка меняет яркость», «Радуга», «Парктроник» …): пример сам ставит нужные модули на плату.
* Проект сохраняется в браузере, можно сохранить в файл `.qbit.json` или как `.py`.

## Симулятор платы: что умеет

* Перетаскивание модулей из списка на порт (магнит притягивает в пределах ~12 мм), снятие — «потянуть, пока магнит не отпустит». Двойной модуль (65 мм) занимает два соседних порта **в ряду**.
* Модули ведут себя как железо: кнопки, ручки, ползунки, джойстик, энкодер, ИК-пульт, датчики (температура/свет/наклон среды), светодиоды, RGB, зуммер (звук через WebAudio), сервопривод, реле, мотор, OLED 128×64.
* Плата по-настоящему «опрашивает» порт: дребезг 0,2 с → чтение паспорта (EEPROM 24C02 @0x50, CRC-16) через TCA9548A → проверка бюджета тока → готов. Неизвестный модуль, перегрузка по току eFuse, просадка 5 В — как на железе.
* Источники питания: USB-ПК 0,5/0,9 А, 5 В/3 А, PD 15 В, аккумулятор; INA226, заряд, кнопка PAIR/POWER, RESET/BOOT, светодиоды.
* Инспектор справа: паспорт (с hex-дампом), линия SIG, I²C-сканер, «Воздействие» (руками), «Проверка выходов», среда (температура, свет, наклон платы, магнитное поле).
* «Демо»: пока нет блочных программ, выходы повторяют входы (кнопка → светодиод и т.п.).
* Сцена сохраняется в `localStorage`, экспорт/импорт JSON в меню `⋯`.

## Устройство кода

```
js/data/hw-data.js     данные из каталога (генерируется)
js/core/               ядро платы без DOM: работает и в Node (тесты, поддельная плата)
  board.js, module.js, modules/*.js   плата, 33 модуля (электрическая модель)
js/runtime/            то, что запускает программы
  spec.js              контракт: значения, команды, события модулей (имена как в прошивке)
  contract.js          «драйверы прошивки» поверх моделей модулей
  pyinterp.js          интерпретатор Python;  runtime.js  — модуль qbit и задачи
js/ui/                 плата, список модулей, инспектор (SVG в мм, чистый JS)
js/ide/                редактор блоков: catalog, blocks, toolbox, editor, device, link, panes, ide
mpy/                   модуль qbit для MicroPython (плата)
docs/, tools/, tests/  документы, генераторы и сборка, тесты
vendor/blockly/        Blockly 13.4.0 (Apache-2.0), без изменений
```

### Как описан модуль

```js
Q.defineModule('button', {
  state:   () => ({ pressed: false }),          // то, что делает человек
  sigOut:  (m) => m.state.pressed ? 3270 : 0,   // напряжение на SIG, мВ
  currentMa: () => 3,
  controls: [{ type: 'hold', id: 'pressed', label: 'Нажать кнопку' }],
  readouts: (m) => [{ label: 'Кнопка', value: m.state.pressed ? 'нажата' : 'отпущена' }],
  api: (m, port) => ({ isPressed: () => port.sig.read() === 1, on: Q.mod.onApi(m) })
});
```

`api` — это драйвер модуля в терминах железа (SIG, I²C). Программа его не видит: между ними слой `js/runtime/contract.js`, который превращает `api` в «значения, команды и события» как у настоящей прошивки. Поэтому блоки и Python-программа одинаковы для симулятора и платы.

Полезные вызовы платы: `attach(n, key, {variant})`, `detach(n)`, `step(dt)` / `run(sec)`, `setSource(id)`, `pressButton('reset'|'boot'|'pair', down)`, `on('attach'|'ready'|'fault'|'step'|…, fn)`, `serialize()` / `restore(json)`.

## Допущения, которые я принял сам (проверьте!)

1. **65-мм модули ставятся только горизонтально** — разъём у них на коротком торце, а полярность магнитов (N слева / S справа) задаёт ориентацию. В тексте каталога («вдоль ряда или столбца») написано иначе — одно из двух надо поправить.
2. Бюджет тока: суммарно ≤ 90 % источника, eFuse 1,8 А / 8 мс на порт, 3 повтора; просадка 5 В ниже 4,1 В → перезапуск платы. Это моя политика, в прошивке её ещё нет.
3. Джойстик: A=вверх, B=вправо, C=вниз, D=влево.
4. Оси IMU/компаса: x вправо, y к USB, pitch>0 поднимает край с USB, roll>0 опускает правый край, yaw — курс. Калибровка компаса (hard-iron) хранится в паспорте, область пользователя 0x80, маркер 0xC5.
5. Долгое нажатие PAIR (2 с) при работе от батареи — выключение.
6. Регистровая эмуляция есть только для энкодера (0x36), ультразвука (0x39), DRV8830 и SSD1306; остальные I²C-чипы отдают готовые значения.
